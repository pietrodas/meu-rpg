# Duelo de Treino

Protótipo de luta arcade para navegador, sem dependências de build.

## Como jogar

Abra `index.html` em um navegador. Use as setas para mover e pular, `A` para golpe,
`S` para golpe forte, `D` para defender e `F` para usar o super quando o medidor
estiver cheio. Escolha **Contra o bot** e selecione a dificuldade fácil, média ou
difícil, ou escolha **Jogador contra jogador** para duas pessoas no mesmo dispositivo.
No modo local, o jogador 1 usa os controles acima; o jogador 2 usa `J`/`L` para mover,
`I` para pular, `U` para golpe, `O` para golpe forte, `P` para defender e `;` para o
super. Os botões na tela também funcionam por toque para o jogador 1. Use
**Reiniciar luta** para começar outra partida.

Escolha a arena entre Brasília, quadra de basquete, salão de chá, academia de treino,
cenário com bomba cenográfica, praça dos Três Poderes e floresta Amazônica.

## Elenco

O elenco disponível é Kim Jong-un, Trump, Bolsonaro, Lula, Obama, Putin, Getúlio
Vargas, JK, Rainha Elizabeth, Mahatma Gandhi, Winston Churchill, Nelson Mandela e Hugo
Chávez, além do alvo de treino como adversário.
Cada personagem tem pixel art original e seus golpes/finalizações cômicos aprovados.
Os combates são cartunescos e sem ferimentos gráficos.

Há interações de entrada especiais entre Kim e Trump, Lula e Trump, Lula e Bolsonaro,
Obama e Trump, Putin e Trump, Rainha Elizabeth e Trump, Gandhi e Rainha Elizabeth, e
Churchill e Rainha Elizabeth, Mandela e Gandhi, e Chávez e Trump. As cenas aparecem ao
iniciar o confronto correspondente.
